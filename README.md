# CricketScoreUpdator

## This is a bot application that runs and update the scorecard of given match in the dynamo db table.

### How To Run the Bot?
- #### Open terminal
- ####  Activate python and navigate to the project directory
- #### Enter ``python main.py --series=series_id --match=match_id``
- ##### Enter ``python main.py --match=match_id`` for IPL 2025 matches
